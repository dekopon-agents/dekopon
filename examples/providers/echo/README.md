# Echo provider

A complete Rust provider implementing `dekopon_provider_sdk::Provider`.

It exports five deterministic, read-only capabilities:

| Capability | Behavior |
|---|---|
| `echo.echo` | Returns any supplied JSON object unchanged. |
| `echo.reverse` | Reverses the Unicode scalar values in `message`. |
| `echo.upcase` | Converts `message` to Unicode uppercase. |
| `echo.downcase` | Converts `message` to Unicode lowercase. |
| `echo.ransom-case` | Alternates alphabetic characters between lowercase and uppercase, starting lowercase and ignoring punctuation when alternating. |

The four text transformations accept exactly one string field and return the same shape:

```json
{"message":"Hello, World!"}
```

Build the core Wasm guest and componentize the WIT metadata generated by the SDK (`cargo install wasm-tools --version 1.236.1 --locked` if needed):

```console
examples/providers/echo/build.sh
```

The checked-in `echo-provider.wasm` is generated from this source and lets `dekopon-run` work immediately. The host intentionally supplies no WASI interfaces, so build for `wasm32-unknown-unknown` and componentize it rather than targeting `wasm32-wasip2`.
